# Project: PVZ Web Clone

## Architecture
- Framework: Pure TypeScript + HTML5 Canvas (Vite as bundler)
- Design Pattern: Object-Oriented Programming (OOP) + Entity-Component Style Loop
- Canvas Resolution: Fixed 900x600

## Code Style Rules
- Use ES6+ TypeScript class constructs.
- Keep rendering logic (`draw`) strictly separated from state updating logic (`update`).
- Do not use external full-blown game engines (like Phaser). Keep it lightweight.
