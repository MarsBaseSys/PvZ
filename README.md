# PvZ Web

一个用纯 TypeScript + HTML5 Canvas 实现的塔防小游戏，灵感来自经典的"植物 vs 僵尸"玩法，但植物、僵尸的设定和美术都是原创重新设计（避免直接复刻某款商业游戏的具体角色形象），附带一个复用同一批素材的双语英语学习小游戏。

**世界观**：一座魔法花园遭遇了"枯萎侵蚀"，腐烂的落叶与枯枝被侵蚀之力唤醒，化作成群的"腐蔓伏尸"（Husk）向花园深处涌来。你要用花园里的各种守护苗（植物）挡住它们。

- 在线仓库：https://github.com/MarsBaseSys/PvZ

## 技术栈

- **纯 TypeScript + HTML5 Canvas**（不依赖 Phaser 等游戏引擎）
- **Vite** 作为构建工具 / 开发服务器
- 面向对象 + 简单的 Entity-Component 风格主循环
- Web Audio API 做音效，Web Speech API 做英语语音播报

## 环境要求

- Node.js（建议 18+）与 npm

## 快速开始

```bash
npm install
npm run dev
```

启动后在浏览器打开终端输出的地址（默认 `http://localhost:5173`）即可开始游戏。

## 可用脚本

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动 Vite 开发服务器（带热更新） |
| `npm run build` | 先跑 `tsc --noEmit` 类型检查，再执行生产构建，产物输出到 `dist/` |
| `npm run preview` | 本地预览 `build` 产物 |

## 怎么玩

1. **选择关卡**：打开游戏后会先看到「选择关卡」界面，3×3 排列全部 9 关，可以自由点击任意一关直接开始，不需要按顺序解锁。
2. **收集阳光**：屏幕上会自然掉落阳光，点击它即可收集（+25）；月苞也会持续产出阳光。
3. **选择植物**：点击顶部卡槽里的植物卡片进行选择（需要阳光足够且不在冷却中）。
4. **种植**：选中植物后，点击草坪上任意一行高亮的格子即可种下（全部 5 行都可以种植）。
5. **抵御伏尸**：伏尸会从右侧向左移动，遇到植物会停下攻击（手臂摆动、张嘴啃咬，可以看到动作）；若伏尸越过草坪左边界，游戏失败，可点击「重新开始」再来一次。
6. **通关**：清空当前关卡所有波次的伏尸后，会出现一张奖励卡片，点击收集即可解锁新植物，并进入下一关；每关最后一波伏尸来袭时，屏幕上会有醒目提示。
7. 右上角的「📖 图鉴」按钮可以随时查看所有植物 / 伏尸的图鉴介绍（会暂停游戏）。

全部 9 关，可在开局的选关界面自由挑选，解锁顺序（首次通关时获得对应奖励植物）：

| 关卡 | 解锁植物 | 说明 |
| --- | --- | --- |
| 1-1 | 月苞 Moonbud | 定期释放阳光，经济核心 |
| 1-2 | 树瘤壁 Bark Bulwark | 血量极高，专职拖延伏尸 |
| 1-3 | 霜百合 Frost Lily | 命中后会减速伏尸 |
| 1-4 | 双牙蔓 Twin Fang | 一次连续甩出两颗种子 |
| 1-5 | 爆裂菇 Blastcap | 种下后立即在周围范围秒杀伏尸 |
| 1-6 | （无新植物，难度陡增的中期关卡） | |
| 1-7 | 燃根桩 Emberroot | 种子穿过它的余烬时伤害翻倍 |
| 1-8 | 幻梦菇 Dreamspore | 被伏尸吃掉时反过来催眠对方，为你作战 |
| 1-9 | 冰川绽 Glacier Bloom | 加大版霜百合，血量厚实、攻击带减速（最终关） |

初始植物为荆棘蔓 Thornsnap（向同一行的伏尸甩出带刺种子）。

伏尸类型：腐蔓伏尸 Husk（普通）、荚壳伏尸 Pod-Head Husk（头顶天然荚壳当护甲）、树桩伏尸 Stump Husk（头肩融合树桩，护甲更厚，中后期关卡出现）。

游戏过程中会有英文语音播报（种植植物、收集阳光、伏尸出现、最后一波来袭等事件），可用于顺带磨耳朵。

美术全部是原创手绘 Canvas 矢量图形，没有使用任何外部图片素材；伏尸攻击时手臂和嘴部会有动画。

## 项目结构

```
├── index.html              # 游戏主页面
├── english-demo.html        # 英语学习 Demo 入口
├── src/
│   ├── main.ts              # 游戏入口
│   ├── config/               # 数值配置（植物/僵尸参数、关卡数据、图鉴文案）
│   ├── engine/                # 核心引擎：GameEngine 主循环、Grid、LevelManager、InputManager
│   ├── objects/               # 游戏实体：Plant、Zombie、Seed、Sun、RewardCard...
│   ├── utils/                  # 工具：音效引擎、语音播报、通用数学函数等
│   └── english-demo/           # 英语学习 Demo 独立小应用
└── vite.config.ts
```

## 彩蛋：英语学习 Demo

主页面右上角有一个「🔤 学英语 Demo」入口（对应 `english-demo.html`），复用游戏里的植物/伏尸/阳光图标做成一个英语单词选择题小游戏（Bud / Thorn / Stump / Husk / Pod 等真实英语词汇），并配有英文语音朗读，适合边玩边学单词。
