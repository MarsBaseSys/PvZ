# PvZ Web

一个用纯 TypeScript + HTML5 Canvas 实现的《植物大战僵尸》网页版克隆，附带一个复用同一批素材的双语英语学习小游戏。

- 在线仓库：https://github.com/MarsBaseSys/PvZ

## 技术栈

- **纯 TypeScript + HTML5 Canvas**（不依赖 Phaser 等游戏引擎）
- **Vite** 作为构建工具 / 开发服务器
- 面向对象 + 简单的 Entity-Component 风格主循环
- Web Audio API 做音效，Web Speech API 做英语语音播报

## 环境要求

- Node.js（建议 18+）与 npm

## 快速开始

```bash
npm install
npm run dev
```

启动后在浏览器打开终端输出的地址（默认 `http://localhost:5173`）即可开始游戏。

## 可用脚本

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 启动 Vite 开发服务器（带热更新） |
| `npm run build` | 先跑 `tsc --noEmit` 类型检查，再执行生产构建，产物输出到 `dist/` |
| `npm run preview` | 本地预览 `build` 产物 |

## 怎么玩

1. **选择关卡**：打开游戏后会先看到「选择关卡」界面，3×3 排列全部 9 关，可以自由点击任意一关直接开始，不需要按顺序解锁。
2. **收集阳光**：屏幕上会自然掉落阳光，点击它即可收集（+25）；向日葵也会持续产出阳光。
3. **选择植物**：点击顶部卡槽里的植物卡片进行选择（需要阳光足够且不在冷却中）。
4. **种植**：选中植物后，点击草坪上任意一行高亮的格子即可种下（全部 5 行都可以种植）。
5. **抵御僵尸**：僵尸会从右侧向左移动，进入你的草坪并攻击植物；若僵尸越过草坪左边界，游戏失败，可点击「重新开始」再来一次。
6. **通关**：清空当前关卡所有波次的僵尸后，会出现一张奖励卡片，点击收集即可解锁新植物，并进入下一关；每关最后一波僵尸来袭时，屏幕上会有醒目提示。
7. 右上角的「📖 图鉴」按钮可以随时查看所有植物 / 僵尸的图鉴介绍（会暂停游戏）。

全部 9 关，可在开局的选关界面自由挑选，解锁顺序（首次通关时获得对应奖励植物）：

| 关卡 | 解锁植物 | 说明 |
| --- | --- | --- |
| 1-1 | 向日葵 Sunflower | 定期产出阳光，经济核心 |
| 1-2 | 坚果墙 Wall-nut | 血量极高，专职拖延僵尸 |
| 1-3 | 寒冰射手 Snow Pea | 豌豆命中后会减速僵尸 |
| 1-4 | 双发射手 Repeater | 一次连续发射两颗豌豆 |
| 1-5 | 樱桃炸弹 Cherry Bomb | 种下后立即在周围范围秒杀僵尸 |
| 1-6 | （无新植物，难度陡增的中期关卡） | |
| 1-7 | 火炬树桩 Torchwood | 豌豆穿过它的火焰时伤害翻倍 |
| 1-8 | 催眠蘑菇 Hypno-shroom | 被僵尸吃掉时反过来催眠对方，为你作战 |
| 1-9 | 冰蘑菇 Ice-shroom | 增强版寒冰射手，血量厚实、攻击带减速（最终关） |

初始植物为豌豆射手 Peashooter（向同一行的僵尸发射豌豆）。

僵尸类型：普通僵尸（Basic）、路障僵尸（Conehead，带护甲）、铁桶僵尸（Buckethead，护甲更厚，中后期关卡出现）。

游戏过程中会有英文语音播报（种植植物、收集阳光、僵尸出现、最后一波来袭等事件），可用于顺带磨耳朵。

## 项目结构

```
├── index.html              # 游戏主页面
├── english-demo.html        # 英语学习 Demo 入口
├── src/
│   ├── main.ts              # 游戏入口
│   ├── config/               # 数值配置（植物/僵尸参数、关卡数据、图鉴文案）
│   ├── engine/                # 核心引擎：GameEngine 主循环、Grid、LevelManager、InputManager
│   ├── objects/               # 游戏实体：Plant、Zombie、Pea、Sun、RewardCard...
│   ├── utils/                  # 工具：音效引擎、语音播报、通用数学函数等
│   └── english-demo/           # 英语学习 Demo 独立小应用
└── vite.config.ts
```

## 彩蛋：英语学习 Demo

主页面右上角有一个「🔤 学英语 Demo」入口（对应 `english-demo.html`），复用游戏里的植物/僵尸/阳光图标做成一个英语单词选择题小游戏，并配有英文语音朗读，适合边玩边学单词。
